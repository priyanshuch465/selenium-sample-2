# Selenium + TestNG + Cucumber POM Sample

## What’s included
- Java Maven project
- Selenium (Java)
- TestNG
- Cucumber
- WebDriverManager (auto-downloads ChromeDriver)
- 5 Page Object Model classes: LoginPage, HomePage, ProductsPage, CartPage, CheckoutPage
- Sample feature: login and add-to-cart on https://www.saucedemo.com/

## Run
1. `mvn clean test`
2. Or run `runner.TestRunner` via your IDE (TestNG)
